# Contributing

Small, focused changes are welcome.

1. Create a branch from `main`.
2. Keep the four-workflow interface focused and preserve process isolation.
3. Run `python -m compileall app.py ui environments training evaluation metrics models replays utils`.
4. Open a pull request describing the user-visible change and how it was tested.

Do not commit checkpoints, reports, logs, local paths, private documents or experiment datasets.
